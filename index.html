rétablir le lien.

INCIDENT #002

Deux PC. Un lien coupé.

Les deux postes doivent communiquer sur le VLAN 10. PC-A utilise 192.168.10.10 et PC-B 192.168.10.20.

  1. Inspecter les interfaces
  2. Réactiver Gi0/2
  3. Aligner le VLAN d’accès
  4. Valider avec un ping
Besoin d’un indice ?

Tape help. Pour configurer : configure terminal, puis interface gi0/2. Utilise no shutdown et switchport access vlan 10, puis end.
